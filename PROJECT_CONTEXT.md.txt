# PROJECT_CONTEXT.md

## Game Title

윤서의 고백은 세이브 로드가 없다

## Genre

Win32 API C++ visual novel with four mini-games.

## Main Design Goal

The project must support adding new mini-games and dialogue cutscenes easily.

The current goal is not to build a perfect engine at once.
The current goal is to build a working framework step by step.

## Current Big Flow

The intended game flow is:

1. Intro Story
2. Notice
   - Explain that mini-game scores increase player stats.
   - Explain that final endings depend on selected heroine and player stats.
3. MiniGame
   - For now, this can be simulated with a test score.
4. ResultScene
   - Shows mini-game score.
   - Shows which player stats increased.
5. ChoiceScene
   - Player chooses one of three heroines.
6. StoryScene
   - Shows the branch story based on selected heroine and current round.
7. Repeat this loop four times.
8. EndingScene
   - The heroine selected the most becomes the ending target.
   - Player stats decide Happy or Bad ending.

## Removed System

The affection system has been removed.

Instead:

- There are four heroine choice opportunities.
- Each heroine has a selection count.
- The heroine selected most often becomes the final ending target.
- Stats decide Happy or Bad ending.

## Heroine Index Rule

0 = 한세아  
1 = 유하린  
2 = 서이린

## Story Branch Rule

There are 4 rounds and 3 heroines.

So branch stories are stored like this:

storyScripts[roundIndex][heroineIndex]

Examples:

storyScripts[0][0] = round 1, Han Sea story  
storyScripts[0][1] = round 1, Yoo Harin story  
storyScripts[0][2] = round 1, Seo Irin story  

storyScripts[1][0] = round 2, Han Sea story  

Total branch stories: 4 * 3 = 12.

## Current Implementation Direction

StoryData stores the 12 branch stories.
StoryScene should receive a vector of DialogueLineInfo through SetDialogues().
GameManager should call StoryData.GetBranchStory(round, heroine) after ChoiceScene returns the selected heroine index.

## Current Target

The current task is to complete this flow:

ResultScene
→ ChoiceScene
→ selected heroine index
→ StoryData.GetBranchStory(currentStoryRound, selectedIndex)
→ StoryScene.SetDialogues(...)
→ Dialogue mode

## Review Focus

When reviewing files, check:

1. compile errors,
2. include path problems,
3. function declaration/definition mismatch,
4. scene transition bugs,
5. duplicate responsibilities,
6. whether StoryData, StoryScene, ChoiceScene, ResultScene, and GameManager responsibilities are cleanly separated,
7. whether future mini-games and cutscenes can be added easily.
