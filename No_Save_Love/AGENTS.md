# 프로젝트 작업 지침

- 이 프로젝트에서 파일을 변경한 작업은 필요한 검증을 마친 뒤 Git 커밋까지 완료한다. 사용자가 해당 작업에서 커밋하지 말라고 명시하면 그 지시를 따른다.
- 한국어 커밋 제목에는 변경 대상과 결과를 구체적으로 적고, 본문에는 변경 이유, 주요 구현 내용, 검증 방법과 결과를 기록한다. 검증하지 못한 부분이 있으면 함께 명시한다.
- 스토리·컷씬처럼 여러 부분을 바꾼 작업은 경로별 내용, 연출과 동작 변경을 본문에서 구분해 설명한다. 단순한 변경은 실제 규모에 맞게 작성하되 제목만으로 끝내지 않는다.
- 서로 독립된 작업은 의미 있는 단위로 나눠 커밋한다. 커밋 수를 늘리기 위한 빈 커밋이나 인위적인 분할은 하지 않는다.
- 커밋 전 변경 범위를 확인하고, 현재 작업과 관계없는 기존 사용자 변경사항은 임의로 포함하지 않는다.
- 게임 실행 코드는 기존 WinAPI 기반 C++로 구현한다. 다른 언어의 제작·검증 도구를 사용하더라도 게임 실행에 그 도구를 의존시키지 않는다.
