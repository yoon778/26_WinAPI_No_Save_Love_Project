# 전체 플레이 개선 — 2026-10-19

## 조작과 메뉴

- 타이틀: 시작, 설정, 장면 회상, 미니게임 연습.
- ESC: 현재 장면 조작 안내, 설정, 사건 노트. 연습·회상에서는 목록 복귀도 제공한다.
- N 또는 이야기 화면의 사건 노트 버튼: 이번 플레이의 다섯 페이지를 연다. 좌우 방향키와 페이지 버튼으로 넘긴다.
- F11: 전체 화면과 창 모드 전환. 화면 비율을 유지하고 남는 영역은 검게 표시한다. 모든 마우스 입력은 같은 비율로 변환한다.
- 기존 Space/Enter 진행, L 대화 로그, F 빨리 감기, S 별도 스킵은 유지한다.

## 움직임과 성능

게임 갱신 주기는 16ms다. PC방·등교길·유혹 피하기·스토리 타이핑과 페이드·크레딧은 실제 경과 시간으로 계산한다. 기존 게임 속도와 점프 궤적을 유지하며 물리 계산은 작은 시간 간격으로 나눈다. 리듬게임은 음악 시각을 사용하고, 장면 전환이 끝나기 전까지 음악도 정지한다. 게임 중 다른 창으로 전환하면 일시정지한다.

스토리의 정적 배경과 그라데이션, 크레딧 배경을 캐시한다. 원화의 연속 눈 깜빡임은 유지한다. 등교길 배경은 미리 크기를 맞추고 바닥 이미지의 투명한 위쪽 영역은 그리지 않는다. 전용 메뉴를 열면 뒤의 게임을 중복 렌더하지 않는다. 정적 메뉴는 입력·크기 변경이 있을 때 다시 그린다.

1920×1080 오프스크린 측정에서 비 배경 스토리는 평균 27.6–29.4ms에서 10.4–11.9ms, 등교길은 20.86ms에서 3.2–9.1ms로 줄었다. 동시 작업 부하에 따라 변동하며 실제 모니터 FPS를 뜻하지 않는다. 크레딧 평균은 0.95ms였다.

## 난이도와 결과

| 항목 | 스토리 | 보통 | 도전 |
| --- | --- | --- | --- |
| PC방 제한 시간 / 오배달 감점 | 60초 / 25점 | 50초 / 50점 | 45초 / 65점 |
| 등교길 시작 하트 | 5 | 3 | 2 |
| 유혹 피하기 시작 하트 | 7 | 5 | 4 |
| 디펜스 시작 자원 / 등장 간격 | 140 / 1.3배 | 110 / 1배 | 90 / 0.85배 |
| 두 리듬게임 판정 시간 여유 | 1.35배 | 1배 | 0.8배 |

보통은 기존 난이도를 기준으로 한다. 진행 중에는 난이도가 고정된다. 튜토리얼이나 결과 화면에서 ESC 설정을 바꾸면 다음 시작·재도전부터 적용된다. 난이도 때문에 곡이나 채보를 중간에 자르지 않는다.

결과에는 실제 배달·피격·수집·노트·거점 기록과 채점 기준 또는 조작 팁을 표시한다. `다시 도전`은 직전 보상을 원상복구한 뒤 같은 게임을 시작한다. 새 결과만 반영하며 보상은 중복되지 않는다. `이야기 계속`은 현재 결과로 진행한다. 최고 점수는 게임·난이도별로 별도 보관한다.

## 이야기와 사건 노트

총 다섯 사건과 여섯 미니게임 구성은 유지한다. 각 사건이 끝나면 사진, 기록 날짜, 제목, 요약, 인물별 만남 횟수가 있는 노트 페이지를 연다. 다섯 번째 사건은 오락실 도입만 본 시점에는 기록하지 않고 전투 뒤 대화까지 완료해야 기록한다. 사진은 기존 배경·인물 원화와 오락실 배경을 조합하며 페이지별로 캐시한다. 날짜는 실제 플레이 기록 날짜다.

이전 사건을 다른 인물과 보낸 경우 필요한 연결 대사만 바꾼다. 세아의 잉크 회상, 하린의 지도·전학·박수 담당, 이린의 기록·책갈피·약속 종이를 실제 선택 이력에 맞춘다. 분기별 소품·표정·배경·BGM은 유지한다. 관련 공연과 엔딩 대사도 이력에 맞춘다.

## 회상·연습과 저장 범위

완료한 15개 사건과 7개 결말을 회상 메뉴에서 다시 볼 수 있다. 잠긴 항목은 제목을 숨긴다. 회상에는 스탯 보상이나 선택 횟수 증가가 없으며 끝나면 목록으로 돌아온다. 엔딩 회상은 대사와 CG·크레딧까지 제공한다.

연습실에서는 여섯 미니게임과 세 동행을 고른다. 연습 결과는 이야기 능력치와 사건 진행에 영향을 주지 않는다. 재도전하거나 연습 목록으로 돌아갈 수 있다.

음악·효과음 음량, 글자 속도, 화면 흔들림, 창 모드, 난이도, 회상 해금, 최고 점수를 `%LOCALAPPDATA%\NoSaveLove\profile.ini`에 저장한다. 장면별 음량 연출은 사용자 음량을 곱한 값으로 재생하여 음소거를 유지한다. 진행 중인 회차와 대화 로그는 디스크에 저장하지 않는다. 저장 실패 시 메뉴에 알려 주며 현재 실행의 설정은 유지한다.
