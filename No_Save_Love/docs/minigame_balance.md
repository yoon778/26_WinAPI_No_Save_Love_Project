# 미니게임 성장 밸런스

## 목표와 엔딩 기준

현재는 여섯 게임을 한 번씩 플레이하고 스탯 0에서 시작한다. 공통 환산 점수 70점 기준으로 각 스탯 62, 히로인별 핵심 합 124가 된다. 잘한 게임의 보상으로 일부 실수를 만회할 수 있지만 한 게임의 만점만으로 해피 엔딩을 보장하지 않는다.

기존 엔딩 조건은 유지한다. 총합 80 이하는 히든, 그 외에는 세아의 재력+대화, 하린의 대화+매력, 이린의 매력+외모가 120 이상일 때 해피다. 히로인은 다섯 번의 만남에서 가장 많이 선택한 인물이며, 동률이면 세아→하린→이린 순서다. 개화 공연 후 인물 선택을 추가하지 않는다.

## 현재 6개 게임의 만점 보상

| 게임 | 재력 | 대화 | 매력 | 외모 | 점수 환산 |
| --- | ---: | ---: | ---: | ---: | --- |
| PC방 알바 | 40 | 15 | 0 | 0 | 50초, 성공 +100 / 오배달 -50, 원점수 1000이 100점 |
| 노래 연습 | 0 | 0 | 28 | 24 | 108초, 기존 콤보 보너스 포함 최종 점수 / 27500 × 100 |
| 등교길 | 0 | 0 | 17 | 40 | 전체 젤리 대비 수집률, 정수 수집률 85 초과면 100점 |
| 유혹 피하기 | 24 | 25 | 0 | 0 | 50초, 남은 하트 기준 0·20·40·60·80·100점 |
| 방과 후 마지막 웨이브 | 16 | 15 | 17 | 16 | 160초 방어 성공 A, 체력 75% 이상 S, 무피해 100점 |
| 개화 공연 | 0 | 25 | 18 | 0 | 원곡 약 272초, 성공률 90% + 박자 정확도 10% |
| 합계 | **80** | **80** | **80** | **80** | 회차 전체 최대 320 |

개화는 대화 비중 5 / 매력 비중 3이다. 해당 스탯을 주는 기존 게임과 보상을 나눈다. 개화 70점 보상은 대화 +19 / 매력 +14다. 전술 디펜스의 비중은 재력 2 / 대화 3 / 매력 3 / 외모 2다. 회피 게임에서는 70점이 나오지 않으므로 동일 점수 비교는 보상 곡선의 기준이며 실제 플레이 조합은 아래에 따로 적었다.

## 점수별 지급률

| 환산 점수 | 등급 | 각 게임 만점 보상 대비 지급률 |
| --- | --- | ---: |
| 0 | F | 0% |
| 20 | D | 20% |
| 40 | C | 40% |
| 50 | C | 55% |
| 60 | B | 70% |
| 70 | B | 77.5% |
| 80 | A | 85% |
| 90 | S | 92.5% |
| 100 | S | 100% |

`StatBalance.h`가 0·40·60·100점 사이를 선형 보간하고 최종 증가량을 반올림한다. 40~60점 구간에서 기본 조작 습득을 보상하고 이후에는 완만하게 증가한다. 등급은 표시용이며 등급 경계에서 보상이 갑자기 뛰지 않는다. 0점 보상은 0, F등급도 실제 점수에 따라 조금 성장한다.

기존 게임은 주 스탯 비중 5, 보조 비중 3이며, 전술 디펜스은 네 스탯을 함께 배분한다. 스탯마다 전체 비중에 따라 80을 나누고 누적 비중의 정수 몫 차이로 배분하여 모든 게임 만점 시 정확히 80이 된다. 이 회차 획득 상한은 UI의 개별 스탯 상한 100과 구별한다.

## 구성별 총량

현재 실행되는 여섯 게임만 `GameWeights`에 등록한다. 게임을 추가할 때 담당 스탯의 기존 보상도 같은 표에서 재배분한다.

| 구성 | 모든 게임 60점 | 모든 게임 70점 | 모든 게임 만점 |
| --- | --- | --- | --- |
| 이전 4개 | 56 / 56 / 56 / 56 | 62 / 62 / 62 / 62 | 80 / 80 / 80 / 80 |
| 이전 5개 | 56 / 57 / 55 / 56 | 62 / 62 / 62 / 62 | 80 / 80 / 80 / 80 |
| 현재 6개 | 56 / 58 / 57 / 56 | 62 / 62 / 62 / 62 | 80 / 80 / 80 / 80 |

순서는 재력 / 대화 / 매력 / 외모다. 일곱 번째 게임을 가정한 균형·편중 구성도 회귀 검사한다.

## 검증

- 현재 여섯 게임의 실제 가능한 점수 조합 `60 / 80 / 80 / 80 / 100 / 80` → `64 / 68 / 70 / 70`, 세 루트 모두 해피.
- 전체 0~100점 보상 단조 증가, 잘못된 번호, 점수 범위 제한, ResultScene 보상, 엔딩 80/81·119/120 경계를 C++로 검사한다.
- 이전 4·5개 / 현재 6개 / 가상 7개 구성 모두 만점 상한을 검사한다.
- 전술 디펜스과 개화 결과는 각각 한 번만 적용되며 이후 다섯 번의 선택 기록으로 엔딩을 판정하는 흐름을 세 히로인 모두 검사한다.
- 수치·자동 판정 검증에 따른 1차 튜닝이다. 실제 플레이어의 점수 분포와 클리어율은 아직 측정하지 않았다.

실행: `powershell -ExecutionPolicy Bypass -File tests/run_stat_checks.ps1`.
