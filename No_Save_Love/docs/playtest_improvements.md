# 플레이 테스트 개선 — 2026-10-15

## 읽기와 조작

- Space / Enter / 클릭: 타이핑 중이면 현재 문장을 완성하고, 완성된 문장이면 다음 대사를 표시한다. 키를 누르고 있어도 반복 입력으로 여러 대사를 넘기지 않는다.
- F / 우측 상단 빨리 감기: 타이핑 속도 4배, 완성 후 0.35초 뒤 다음 대사를 순서대로 표시한다. 다시 누르면 정지한다. 마우스나 Space로 수동 진행해도 배속이 꺼진다. 배속 중에도 배경 전환과 BGM 변경, 로그 기록을 수행한다.
- L / 대화 로그: 현재 실행에서 끝까지 표시한 대사를 조회한다. 휠, 위아래 방향키, Page Up/Down, 이전·최근 버튼으로 탐색한다. Home/End는 처음·끝으로 이동한다. Esc/L/닫기로 복귀한다. 로그를 열면 진행과 배속이 멈춘다.
- 로그는 장면·분기·미니게임 사이에 유지된다. 게임을 종료하거나 크레딧에서 처음으로 돌아가면 지워진다. 디스크 저장 기능은 없다.

긴 이름은 320px 영역에서 실제 글꼴 폭을 측정해 한 줄에 맞춘다. 모든 빌드 구성에 `/utf-8`을 적용한다.

## 전용 화면과 연출

인트로의 시스템 설명 세 줄은 중앙 튜토리얼 페이지로 표시한다. 튜토리얼 진입 시 배속을 해제하고 직접 확인해야 다음으로 진행한다.

학생·친구 메시지, 하린과 이린의 문자, 프롤로그의 주인공 답장은 휴대폰 화면으로 표시한다. 연속 메시지는 말풍선으로 남고, 받은 메시지는 왼쪽, 내 답장은 오른쪽에 배치한다. 해당 대사에는 일반 대화창을 그리지 않는다.

세 히로인마다 `resource/heroine/<이름>/animation.png`에 3열×2행의 표정 시트를 추가했다. 순서는 평상시, 반쯤 감은 눈, 감은 눈, 말하기, 수줍은 미소, 놀람이다. ImageGen으로 기존 원화를 참고해 제작한 18개 프레임을 사용한다. 얼굴 픽셀을 늘이거나 머리와 목을 비트는 계산을 제거하고, 작은 위치 이동과 프레임 교체로 눈 깜빡임·발화·감정 반응을 표현한다. 시트를 읽지 못하면 기존 원화를 표시한다.

일상 배경에는 햇살·부유 먼지·꽃잎을 추가했다. 세 번째 만남은 세 경로 모두 창가 비를 유지하며 소품 애니메이션과 함께 재생한다. 배경 효과는 히로인과 대화창 뒤에 그린다.

## 크레딧과 처음으로

크레딧의 F / Space / 빨리 감기 버튼은 1배·4배 전환이다. 크레딧이 끝나면 `처음으로 · Enter`와 `게임 종료` 버튼을 표시한다. 처음으로 돌아갈 때 이름·스탯·선택 횟수·스토리 회차·로그·배속을 초기화하며, 리소스를 중복 초기화하지 않는다.
