# 플레이 테스트 개선 — 2026-10-15

## 읽기와 조작

- Space / Enter / 클릭: 타이핑 중이면 현재 문장을 완성하고, 완성된 문장이면 다음 대사를 표시한다. 키를 누르고 있어도 반복 입력으로 여러 대사를 넘기지 않는다.
- F / 우측 상단 빨리 감기: 타이핑 속도 16배, 완성 후 0.10초 뒤 다음 대사를 순서대로 표시한다. 다시 누르면 정지한다. 마우스나 Space로 수동 진행해도 배속이 꺼진다. 배속 중에도 배경 전환과 BGM 변경, 로그 기록을 수행한다.
- S / 우측 상단 스킵: 현재 대사 묶음을 즉시 완료한다. 건너뛴 대사·메시지·안내도 로그에 남고, 마지막 배경과 BGM 상태를 적용한다. 선택지나 미니게임을 대신 진행하지 않는다. 엔딩 대사에서는 크레딧으로 이동한다. 버튼은 배속과 별도로 높이 40px이며 단축키 설명은 ESC 메뉴에 표시한다.
- L / 대화 로그: 현재 실행에서 끝까지 표시한 대사를 조회한다. 휠, 위아래 방향키, Page Up/Down, 이전·최근 버튼으로 탐색한다. Home/End는 처음·끝으로 이동한다. Esc/L/닫기로 복귀한다. 로그를 열면 진행과 배속이 멈춘다.
- ESC는 현재 장면의 조작 안내를 연다. 메뉴에서 계속하기 또는 ESC로 돌아온다. 스토리의 배속은 메뉴 진입 시 해제된다. 버튼 위 단축키 표기는 제거했고, 스토리 버튼은 높이 40px로 줄였다.

로그는 장면·분기·미니게임 사이에 유지된다. 게임을 종료하거나 크레딧에서 처음으로 돌아가면 지워진다. 디스크 저장 기능은 없다.

긴 이름은 320px 영역에서 실제 글꼴 폭을 측정해 한 줄에 맞춘다. 모든 빌드 구성에 `/utf-8`을 적용한다.

## 전용 화면과 연출

인트로는 노트의 반복 규칙, 다섯 번의 만남, 세 히로인의 고민, 능력치 성장, 최종 상대와 공연, 읽기 기능을 설명하는 중앙 튜토리얼 여섯 장으로 표시한다. 튜토리얼 진입 시 배속을 해제하고 직접 확인해야 다음으로 진행한다.

설명 화면은 기존 `open_book.png`를 펼친 안내서로 사용한다. 왼쪽에는 페이지별 삽화와 핵심 문장, 오른쪽에는 제목과 본문을 배치한다. 크림색 종이와 분홍 리본·버튼, 여섯 개의 진행 표시를 사용하고, 마지막 버튼은 `이야기 시작하기`로 표시한다. 히로인 소개에는 기존 세 인물 원화를 사용한다. 새 이미지나 외부 실행 의존성은 추가하지 않는다.

학생·친구 메시지, 하린과 이린의 문자, 프롤로그의 주인공 답장은 휴대폰 화면으로 표시한다. 연속 메시지는 말풍선으로 남고, 받은 메시지는 왼쪽, 내 답장은 오른쪽에 배치한다. 해당 대사에는 일반 대화창을 그리지 않는다.

눈 깜빡임은 기존 원화의 눈 주위를 연속적으로 닫고 여는 방식으로 복원했다. 깜빡일 때 전신 표정 시트를 교체하지 않는다. 기존보다 고개 회전과 상체 이동 폭을 줄였다. 제작했던 18프레임 이미지 파일은 보존하며, 현재 기본 캐릭터 재생은 원화를 사용한다.

같은 회차에서 서로 다른 히로인이 공통 소품 애니메이션을 쓰지 않도록 분리했다. 세아의 봉투·라벨·우유 건네기는 유지한다. 하린은 유리창의 빗방울을 손끝으로 따라가고, 이린은 책 분류표 수선·원고 펼치기·거꾸로 든 빨대를 돌린 뒤 공책으로 가리기를 사용한다. 전체 소품 애니메이션은 22종이다.

도서관 비는 중앙 창 유리 안에서만 작게 움직이고 책장·실내에는 그리지 않는다. `library_day.png`의 구도를 유지한 흐린 날 배경 `library_rain.png`를 ImageGen으로 제작하여 비 장면에서 사용한다. 실내 일반 배경에서는 rain 효과 때문에 카메라가 확대되거나 히로인이 사라지지 않는다. 복도·교실·학생회실도 원화 창 위치에 맞춰 마스크를 나눴다. 햇살·먼지·꽃잎 효과는 유지한다.

## 크레딧과 처음으로

크레딧의 F / Space / 빨리 감기 버튼은 1배·16배 전환이다. 크레딧이 끝나면 `처음으로`와 `게임 종료` 버튼을 표시한다. 처음으로 돌아갈 때 이름·스탯·선택 횟수·스토리 회차·로그·배속을 초기화하며, 리소스를 중복 초기화하지 않는다.

## 확인 방법

- `tests/run_story_checks.ps1`: 모든 스토리 경로, 긴 이름·플레이어 치환, 배속의 순차 기록, 로그에서 입력·시간 정지, 튜토리얼 정지, 메시지와 답장, 4종 배경 효과, 연속 눈 깜빡임과 경로별 소품 연출을 검사하고 실제 Win32 렌더 이미지로 저장한다.
- `tests/run_flowering_checks.ps1`: 실제 Windows MP3 재생, 225개 노트 전곡 판정·GOOD/BAD 성공 S등급, 앵콜 뒤 최소 1.384초, 기존 리듬게임, 세 히로인의 엔딩 연결, 크레딧 배속·처음으로·새 게임과 키보드/로그를 검사한다. Windows 오디오에 접근 가능한 환경에서 실행한다.
- 개화 채보의 상세 수치와 참고 자료는 [개화 미니게임 문서](flowering_minigame.md)에 기록했다.

## 배포본 효과음

긴 배포 경로에서 MCI `waveaudio`가 WAV 열기 오류 304를 반환하는 문제를 재현했다. 공통 효과음과 리듬게임의 WAV 재생기를 `mpegvideo`로 바꿨다. 파일 이름·내용은 유지한다. `tests/run_flowering_checks.ps1`은 실제 소스·배포 폴더 양쪽에서 등록 효과음 22개를 열고 재생·재시작하며, BGM 동시 재생도 검사한다. 사람의 청감 검증과는 구분한다.

## 다섯 번째 미니게임 — 방과 후 마지막 웨이브

약속 퍼즐을 3개 진입로의 전술 디펜스로 교체했다. 20초 연습과 160초 실전, 네 유닛의 배치·회수, 두 번의 강화, 보스와 히로인별 지원을 제공한다. 네 번째 사건 뒤에 동행 선택을 추가해 총 다섯 사건을 기록한다. 개화 공연은 여섯 번째 게임이며 최종 상대는 다섯 선택을 합산한다.

세아는 연결 방어와 보호막, 하린은 연속 처치와 돌진, 이린은 감속과 범위 공격을 중심으로 플레이한다. 승패에 맞는 대사 뒤에 오락실에서 함께 논 일을 기록한다. 클리어는 A, 체력 75% 이상은 S, 무피해는 100점이다.

규칙·스토리·검증은 [전술 디펜스 문서](promise_minigame.md)에 기록했다. 리듬게임 2·6의 ESC 커서 복구와 스토리 스킵·배속은 유지한다.
