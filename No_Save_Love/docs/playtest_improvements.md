# 플레이 테스트 개선 — 2026-10-15

## 읽기와 조작

- Space / Enter / 클릭: 타이핑 중이면 현재 문장을 완성하고, 완성된 문장이면 다음 대사를 표시한다. 키를 누르고 있어도 반복 입력으로 여러 대사를 넘기지 않는다.
- F / 우측 상단 빨리 감기: 타이핑 속도 16배, 완성 후 0.10초 뒤 다음 대사를 순서대로 표시한다. 다시 누르면 정지한다. 마우스나 Space로 수동 진행해도 배속이 꺼진다. 배속 중에도 배경 전환과 BGM 변경, 로그 기록을 수행한다.
- L / 대화 로그: 현재 실행에서 끝까지 표시한 대사를 조회한다. 휠, 위아래 방향키, Page Up/Down, 이전·최근 버튼으로 탐색한다. Home/End는 처음·끝으로 이동한다. Esc/L/닫기로 복귀한다. 로그를 열면 진행과 배속이 멈춘다.
- ESC는 현재 장면의 조작 안내를 연다. 메뉴에서 계속하기 또는 ESC로 돌아온다. 스토리의 배속은 메뉴 진입 시 해제된다. 버튼 위 단축키 표기는 제거했고, 스토리 버튼은 높이 40px로 줄였다.

로그는 장면·분기·미니게임 사이에 유지된다. 게임을 종료하거나 크레딧에서 처음으로 돌아가면 지워진다. 디스크 저장 기능은 없다.

긴 이름은 320px 영역에서 실제 글꼴 폭을 측정해 한 줄에 맞춘다. 모든 빌드 구성에 `/utf-8`을 적용한다.

## 전용 화면과 연출

인트로는 노트의 반복 규칙, 네 번의 만남, 세 히로인의 고민, 능력치 성장, 최종 상대와 공연, 읽기 기능을 설명하는 중앙 튜토리얼 여섯 장으로 표시한다. 튜토리얼 진입 시 배속을 해제하고 직접 확인해야 다음으로 진행한다.

학생·친구 메시지, 하린과 이린의 문자, 프롤로그의 주인공 답장은 휴대폰 화면으로 표시한다. 연속 메시지는 말풍선으로 남고, 받은 메시지는 왼쪽, 내 답장은 오른쪽에 배치한다. 해당 대사에는 일반 대화창을 그리지 않는다.

눈 깜빡임은 기존 원화의 눈 주위를 연속적으로 닫고 여는 방식으로 복원했다. 깜빡일 때 전신 표정 시트를 교체하지 않는다. 기존보다 고개 회전과 상체 이동 폭을 줄였다. 제작했던 18프레임 이미지 파일은 보존하며, 현재 기본 캐릭터 재생은 원화를 사용한다.

같은 회차에서 서로 다른 히로인이 공통 소품 애니메이션을 쓰지 않도록 분리했다. 세아의 봉투·라벨·우유 건네기는 유지한다. 하린은 유리창의 빗방울을 손끝으로 따라가고, 이린은 책 분류표 수선·원고 펼치기·거꾸로 든 빨대를 돌린 뒤 공책으로 가리기를 사용한다. 전체 소품 애니메이션은 22종이다.

도서관 비는 중앙 창 유리 안에서만 작게 움직이고 책장·실내에는 그리지 않는다. `library_day.png`의 구도를 유지한 흐린 날 배경 `library_rain.png`를 ImageGen으로 제작하여 비 장면에서 사용한다. 실내 일반 배경에서는 rain 효과 때문에 카메라가 확대되거나 히로인이 사라지지 않는다. 복도·교실·학생회실도 원화 창 위치에 맞춰 마스크를 나눴다. 햇살·먼지·꽃잎 효과는 유지한다.

## 크레딧과 처음으로

크레딧의 F / Space / 빨리 감기 버튼은 1배·16배 전환이다. 크레딧이 끝나면 `처음으로`와 `게임 종료` 버튼을 표시한다. 처음으로 돌아갈 때 이름·스탯·선택 횟수·스토리 회차·로그·배속을 초기화하며, 리소스를 중복 초기화하지 않는다.

## 추가 미니게임 추천 — 노트 밖의 약속 (제안, 미구현)

네 번째 만남 뒤, 기존 개화 공연 준비 앞에 90~120초의 물건 연결 퍼즐을 권한다. 빠른 회피 게임과 긴 리듬게임 사이에서 속도를 낮추고, 노트 안의 기록이 흐려져도 현실의 약속은 남길 수 있다는 주제를 직접 행동으로 보여준다.

### 조작과 구성

탁자 위 물건 6~8개를 클릭해 읽고, 단서에 맞는 보관 위치로 끌어 놓는다. 세 장면에서 물건의 짝 찾기, 순서 맞추기, 작은 상자 배치를 하나씩 익힌다. 단서는 계속 화면에 남겨 앞 대사를 외워야 풀리는 퀴즈가 되지 않게 한다. 정답이면 물건과 연결된 짧은 대사가 나오며, 오답은 부드럽게 되돌아온다. 엄격한 제한시간 없이 완료 수·힌트 사용을 중심으로 등급을 계산한다.

### 앞뒤 연결과 구현 범위

공통 도입은 노트 가장자리의 글씨가 흐려지는 장면이다. 주인공은 반복을 상대에게 설명하지 않고 '오늘 한 일을 여기에도 남겨두자'고 제안한다. 각 경로의 정리가 끝나면 히로인이 금요일 작은 무대에 그 물건 하나를 가져오기로 한다. 기존 공연 응원과 엔딩의 약속으로 자연스럽게 이어진다. 노트의 정체나 반복을 상대에게 고백하는 전개는 넣지 않는다.

추가할 때는 현재 네 번의 선택으로 정한 상대와 이 장면을 진행하는 구성을 권한다. 기존 네 장 규칙을 유지하면서 총 미니게임은 여섯 개가 되고 개화가 여섯 번째로 이동한다. 별도의 다섯 번째 선택까지 원한다면 노트 규칙과 동률 기준부터 함께 다시 설계해야 한다. 보상은 `StatBalance::GameWeights`에 추가해 총 성장 예산을 유지한다. 이번 작업에는 해당 게임과 새 정식 대사를 구현하지 않았다.
