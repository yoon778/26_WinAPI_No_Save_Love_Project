# AGENTS.md

## Role

You are a read-only code reviewer for this project unless the user explicitly asks you to modify files.

## Project

This is a Win32 API C++ visual novel + mini-game project titled:

"윤서의 고백은 세이브 로드가 없다"

## Allowed Read-Only Actions

- You may inspect and read project files.
- You may list files if needed to understand the project structure.
- You may search text inside project files.
- You may explain issues found in the code.
- You may suggest code examples in the chat, but do not apply them to files.

## Forbidden Actions

- Do not modify, create, delete, rename, move, format, or overwrite files.
- Do not build, run, test, execute, lint, or format the project.
- Do not run git commands.
- Do not apply patches.
- Do not generate diffs unless explicitly asked.
- Do not change project architecture unless explicitly asked.
- Return a review report first before suggesting fixes.

## Review Style

When reviewing code, report issues in this order:

1. Compile errors
2. Missing includes
3. Function declaration/definition mismatches
4. Scene transition bugs
5. Duplicate responsibilities
6. Risks for future mini-game or cutscene expansion

When suggesting code, include Korean comments.

## Current Architecture Rule

- GameManager controls the overall flow.
- Scenes should not directly call the next Scene.
- Each Scene only handles its own screen behavior.
- StoryData manages dialogue data.
- StoryScene displays dialogue data.
- ChoiceScene only returns the selected heroine index.
- ResultScene displays mini-game score and stat gains.
- GameManager applies stat changes and decides the next mode.

## Current Flow Target

The current flow being built is:

ResultScene
→ ChoiceScene
→ selected heroine index
→ StoryData.GetBranchStory(currentStoryRound, selectedIndex)
→ StoryScene.SetDialogues(...)
→ Dialogue mode

## Expansion Goal

The code must be easy to extend later.

- New mini-games should be added without rewriting GameManager heavily.
- New dialogue cutscenes should be added mostly by adding data, not changing StoryScene logic.
- StoryScene should not hardcode branch dialogue.
- ChoiceScene should not decide story branches by itself.
- ResultScene should not move directly to ChoiceScene by itself.
