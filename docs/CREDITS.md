# 팀 역할과 자산 출처

이 문서는 현재 소스의 [엔딩 크레딧](../No_Save_Love/No_Save_Love/StoryData.cpp)에 기록된 내용을 정리한다.
파일별 저작권자·원본 URL·사용 허가까지 확인한 라이선스 명세는 아니다.

## 팀 역할

| 팀원 | 크레딧에 명시된 역할 |
| --- | --- |
| 김새누 | 공동 프로그래밍, PC방 알바, 노래연습 |
| 최윤서 | 시나리오, 공동 프로그래밍, 등교길, 유혹피하기 |

크레딧의 기획 표기는 `26_WinAPI_Programming_Project`이다.
공통 시스템의 파일별 담당과 기여율은 별도 확인이 필요하다. 기획서에 있는 주차별 역할은 계획이므로 완료된 개인 기여와 구분한다.

## 음악

게임 내 크레딧에 기재된 제목과 용도를 보존했다. 개별 MP3/WAV와의 완전한 대응 관계나 허가 여부는 확정하지 않았다.

| 용도 | 크레딧 표기 |
| --- | --- |
| 타이틀 | Cherry Blossom Route — Suno AI 생성 |
| 엔딩 | Frozen Truth — Suno AI 생성; 테일즈위버 OST — Reminiscence; MapleStory — Reproduced Abyss A |
| 스토리 | MapleStory — YumYum Island: Illiyard Moor; GODDESS OF VICTORY: NIKKE — Marian; MapleStory — Lara: Life is Full of Happiness |
| 스토리 | Candy Combo Dash — Suno AI 생성; PRINCESS CONNECT! Re:Dive ORIGINAL SOUNDTRACK — ハッピーエンドのその先で |
| 스토리 | MapleStory — Leafre; MapleStory — Ereve: Raindrop Flower; Rainy Route — Suno AI 생성; MapleStory — Sellas: Where Stars Rest |
| PC방 알바 | MapleStory — BadGuys |
| 노래연습 | QWER — discord |
| 등교길 | MapleStory — Hotel Arcs: Train Heading Nowhere |
| 유혹피하기 | Suno AI 생성, 곡명 미기재 |

`resource`에 들어 있는 효과음의 파일별 원출처·사용 조건은 크레딧만으로 확인되지 않는다.
소스의 출처 표기는 해당 음원이나 이미지의 재배포 권한을 보장하지 않는다. 공개 배포본을 별도로 제공할 때에는 허가 근거가 있는 자산으로 구성해야 한다.
저장소에서 별도의 `LICENSE` 파일은 확인하지 못했으며, 이 문서로 새로운 라이선스를 부여하지 않는다.
